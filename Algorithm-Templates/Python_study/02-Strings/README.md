# 02 · 字符串

> 目标：熟练操作字符串——切片、格式化、常用方法。

## 知识点

1. **写法**：单引号 `'...'`、双引号 `"..."`（两者等价）、三引号 `"""..."""`（多行）
2. **拼接与重复**：`"ab" + "cd"`、`"ab" * 3`（`"-" * 30` 画分割线的常用技巧）
3. **索引与切片**
   - 索引从 `0` 开始，负数表示从右往左：`s[-1]` 是最后一个字符
   - 切片：`s[开始:结束:步长]`，**含头不含尾**
   - `s[:3]`、`s[3:]`、`s[::-1]`（反转）、`s[::2]`（隔一个取一个）
   - 越界切片不会报错（返回空串），但 `s[100]` 会 `IndexError`
4. **字符串不可变**：`s[0] = "x"` 报错；要改只能生成新字符串
5. **f-string 格式化**（重点）：`f"{x}"`、`{x:.2f}`、`{x:>10}`、`{x:,}`（千分位）
6. **常用方法**（返回新字符串，原串不变）
   | 方法 | 作用 |
   | :--- | :--- |
   | `strip()` / `lstrip()` / `rstrip()` | 去首尾空白（处理输入必备） |
   | `split(sep)` / `rsplit` | 切分成 list，默认按空白切 |
   | `"sep".join(可迭代对象)` | 拼成字符串（比 `+` 快） |
   | `replace(old, new)` | 替换 |
   | `find` / `index` / `in` | 查找（`find` 找不到返回 -1，`index` 报错；`in` 返回 bool） |
   | `startswith` / `endswith` | 判断前后缀 |
   | `upper` / `lower` / `title` / `capitalize` | 大小写 |
   | `count` / `zfill` / `center` | 计数 / 左补零 / 居中 |
7. **逐字符遍历**：`for ch in s:`
8. **编码**：Python 3 的 `str` 是 Unicode；转字节用 `s.encode("utf-8")`

## 易错点

- 切片**含头不含尾**：`"hello"[0:3]` 是 `hel`，不是 `hell`
- `s[0]` 和 `s[0:1]` 类型不同：前者是字符，后者仍是字符串
- `split()` 不传参数时，多个连续空格会被当成一个；传 `","` 时空串会保留
- 字符串比较是按 Unicode 码位逐字符比，`"10" < "9"` 是 `True`
- `strip()` 会去掉首尾**所有**空白（含 `\n`、`\t`），别误当成只去空格
- 大量拼接别用 `+` 循环，用 `"".join(list)` 或 f-string

2. 把用户输入的 `"  你好， 世界  "` 清洗成 `"你好，世界"`
3. 用 `split` + `join` 把 `"a,b,c"` 变成 `"a | b | c"`
4. 统计一句话里单词个数、以及某个字符出现了几次
5. 用 f-string 输出「商品名右对齐 10 位 + 价格保留 2 位 + 千分位」
