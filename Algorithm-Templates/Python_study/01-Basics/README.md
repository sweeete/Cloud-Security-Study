# 01 · 基础语法

> 目标：会定义变量、认识基本类型、会做运算和类型转换。

## 知识点

1. **变量**：不用声明类型，赋值即创建；名字用 `snake_case`
   - 合法：字母、数字、下划线，不能数字开头，不能是关键字
   - `=` 是赋值，`==` 才是比较
2. **基本数据类型**
   | 类型 | 写法 | 说明 |
   | :--- | :--- | :--- |
   | `int` | `10` | 整数，**不限长度** |
   | `float` | `3.14` | 浮点数，有精度误差（`0.1 + 0.2 != 0.3`） |
   | `str` | `"abc"` | 字符串（第 02 节专讲） |
   | `bool` | `True` / `False` | 首字母大写 |
   | `NoneType` | `None` | 表示「空」，只有一个值 |
3. **运算符**
   - 算术：`+ - * /`，整除 `//`，取模 `%`，幂 `**`
   - 注意：`/` 结果一定是 `float`（`6 / 2 → 3.0`）
   - 比较：`== != > < >= <=`，返回 `bool`，可以连写 `0 < x < 10`
   - 逻辑：`and or not`，有短路特性
   - 位运算（了解）：`& | ^ ~ << >>`
   - 增强赋值：`+= -= *= //= **=`（Python 没有 `++`）
4. **类型转换**：`int("42")`、`float("3.14")`、`str(123)`、`bool(0)`
   - `int("3.14")` 会报错，要先 `float` 再 `int`
5. **真值判断**：`0`、`0.0`、`""`、`[]`、`{}`、`None` 都算「假」，其余为真
6. **f-string**（3.6+，最常用）：`f"{name} 今年 {age} 岁"`

## 易错点

- `0.1 + 0.2 == 0.3` → `False`（浮点误差）。比较浮点要用 `math.isclose(a, b)`
- `7 / 2` 是 `3.5`，`7 // 2` 才是 `3`；负数整除是「向下取整」：`-7 // 2 == -4`
- `"1" + 2` 报 `TypeError`：字符串和数字不能直接加，要么 `int("1") + 2`，要么 `f"{'1'}{2}"`
- `and` / `or` 返回的不一定是 `bool`：`"" or "default"` 得到 `"default"`（这个特性常被拿来设默认值）
- 变量名 `list`、`sum`、`type` 是内置函数名，别覆盖
