# 03 · 流程控制

> 目标：会用条件判断和循环，能处理「重复做」和「按情况做」的问题。

## 知识点

1. **if / elif / else**
   - 条件后面必须跟 `:`，代码块靠缩进
   - 从上往下判断，命中一个就跳出整个 if 链
   - 条件可以是任意表达式，Python 会自动做真值判断（见 01 节）
2. **三元表达式**：`等级 = "及格" if score >= 60 else "不及格"`
3. **while 循环**：条件为真就一直转，**必须**有让条件变化的语句，否则死循环
4. **for 循环**：遍历可迭代对象（字符串、list、range、dict…）
   - `range(5)` → 0..4；`range(1, 6)` → 1..5；`range(0, 10, 2)` → 0,2,4,6,8
   - `range` 也是「含头不含尾」
5. **`enumerate`**：同时拿到下标和值 → `for i, v in enumerate(items):`
6. **`zip`**：并行遍历多个序列 → `for a, b in zip(list1, list2):`
7. **循环控制**
   - `break` 直接跳出整个循环
   - `continue` 跳过本轮，进入下一轮
   - `else` 挂在循环上：**循环正常结束（没被 break）时执行**，常用于「找没找到」
8. **嵌套循环**：外层走一次，内层走一圈；注意复杂度
9. **`pass`**：占位，什么都不做（先搭结构、后填逻辑时用）

## 易错点

- 忘记冒号 `:`、缩进不一致 → `IndentationError` / `SyntaxError`
- `while` 里忘了更新条件 → 死循环（Ctrl + C 中断）
- `for i in range(1, 5)` 只跑到 `4`，别写成 `range(1, 5)` 却以为包含 5
- `for` 循环里改列表长度会踩坑，要改就遍历副本 `items[:]`
- 循环 `else` 很容易看错：它**不是**「循环没执行时」，而是「没被 `break` 打断时」
- 缩进混用 Tab 和空格会报错，统一 4 个空格
