# 0004. 寻找两个正序数组的中位数（Median of Two Sorted Arrays）

## 一、题目理解

**问题**：给定两个**升序**数组 `nums1` 和 `nums2`，找出它们合并后的**中位数**。

**要求**：时间复杂度 **O(log(m+n))**

**关键点**：
- 两个数组都是**正序**（升序）
- 中位数：奇数个 → 中间那个；偶数个 → 中间两个的平均值
- O(log) 提示用**二分查找**

**示例**：
```
nums1 = [1,3], nums2 = [2]      → 合并 [1,2,3]  → 中位数 2
nums1 = [1,2], nums2 = [3,4]    → 合并 [1,2,3,4] → 中位数 (2+3)/2 = 2.5
```

## 二、算法思路：二分查找分割

### 2.1 暴力法（不满足 O(log)）

```python
# 合并两个数组，取中位数
merged = sorted(nums1 + nums2)  # O((m+n)log(m+n)) ❌
n = len(merged)
return merged[n//2] if n%2 else (merged[n//2-1] + merged[n//2]) / 2
```

### 2.2 二分查找分割（最优解）

**核心思想**：不真的合并，而是用二分查找找到正确的**分割点**。

在较短的数组上二分，确定一个分割位置 `i`，然后根据 `i` 算出另一个数组的分割位置 `j`，使得：
- 左半部分元素个数 = 右半部分元素个数（或差1）
- 左半部分所有元素 ≤ 右半部分所有元素

```
较短数组:  X = X0 | X1  X2  X3  X4    (分割在 i)
较长数组:  Y = Y0  Y1  Y2 | Y3  Y4    (分割在 j)
                    ↓
左半: X0 + Y0 Y1 Y2       右半: X1 X2 X3 X4 + Y3 Y4
条件: max(左半) ≤ min(右半)
```

### 2.3 复杂度

- **时间 O(log(min(m, n)))** — 在较短的数组上二分
- **空间 O(1)** — 只用了几个变量

## 四、C 语言底层 — 指针与边界

C 版本的关键在于：
- **数组名即指针**：`nums1` 是指向数组首元素的指针
- **指针算术**：`*(nums1 + i)` 等价于 `nums1[i]`
- **边界处理**：用条件表达式处理 `i=0` 或 `i=m` 时的边界情况
- **内存分配**：用 `malloc` 创建结果数组（如果要求返回中位数数组）

## 五、手动推演

以 `nums1 = [1,3], nums2 = [2]` 为例：

```
m = 2, n = 1, 确保 m ≤ n: 已是

二分 nums1:
low = 0, high = 2

i = 1, j = (3+1+1)/2 - 1 = 1

分割:
X: [1 | 3]     i=1
Y: [2 | ]      j=1

左: max(1, 2) = 2
右: min(3, ∞) = 3
2 ≤ 3 ✅ 找到中位数

总数奇数 → maxLeft = 2
返回 2.0 ✅
```
