# 0004. 寻找两个正序数组的中位数（Median of Two Sorted Arrays）

> 本文档基于学习过程中的提问与回答整理而成。

---

## 一、题目理解

**问题**：给定两个升序数组 `nums1` 和 `nums2`，找出它们合并后的**中位数**。

**要求**：时间复杂度 **O(log(m+n))**

**示例**：
```
nums1 = [1,3], nums2 = [2]      → 合并 [1,2,3]  → 中位数 2
nums1 = [1,2], nums2 = [3,4]    → 合并 [1,2,3,4] → 中位数 (2+3)/2 = 2.5
```

---

## 二、为什么要用二分查找？（学习时的第一个疑问）

> **问：两个数组已经排序好了，我直接双指针遍历到中间位置不就行了？**

确实可以，双指针遍历法：

```python
def findMedian(nums1, nums2):
    m, n = len(nums1), len(nums2)
    mid = (m + n) // 2
    i = j = 0
    prev = curr = 0
    for _ in range(mid + 1):
        prev = curr
        if i < m and (j >= n or nums1[i] <= nums2[j]):
            curr = nums1[i]; i += 1
        else:
            curr = nums2[j]; j += 1
    return curr if (m+n) % 2 else (prev + curr) / 2.0
```

这个代码逻辑清晰，**能通过**。但时间复杂度是 **O(m+n)**，而题目要求 **O(log(m+n))**。

```
数据规模     O(m+n)     O(log(m+n))
  1万       1万步       ~14步
  10万      10万步      ~17步
  100万     100万步     ~20步
```

O(log) 是这道题的**考点**——提示你用二分查找。

## 三、核心原理：分割法

### 3.1 中位数的本质

> **中位数就是把所有数分成左右两半，使得左半数量 = 右半数量（或差1），且左半所有数 ≤ 右半所有数。**

所以问题转化为：**在两个数组上分别切一刀，让切出来的左右两部分满足中位数的定义。**

```
nums1 = [1, 3, 5, 7]        → 切在 i=2，左边 [1,3] 右边 [5,7]
nums2 = [2, 4, 6, 8]        → 切在 j=2，左边 [2,4] 右边 [6,8]

左半合并: [1,3] + [2,4] = [1,2,3,4]    ← 4个元素
右半合并: [5,7] + [6,8] = [5,6,7,8]    ← 4个元素

检查: max(左)=4  ≤  min(右)=5  ✅
→ 中位数 = (4+5)/2 = 4.5
```

### 3.2 需要满足的两个条件

**条件①：左右数量平衡**

```python
total_left = (m + n + 1) // 2   # 左半需要的元素个数
j = total_left - i               # 另一个数组的分割点由公式确定
```

**条件②：左半所有值 ≤ 右半所有值**

因为两个数组各自已排序，内部自然满足 `左 ≤ 右`，只需要检查跨数组的两个交叉条件：

| 检查 | 含义 |
|:----|:------|
| `nums1_left ≤ nums2_right` | nums1 左边的数不能比 nums2 右边大 |
| `nums2_left ≤ nums1_right` | nums2 左边的数不能比 nums1 右边大 |

只要 `max(nums1_left, nums2_left) ≤ min(nums1_right, nums2_right)`，就保证了左半每个数 ≤ 右半每个数。

> **问：是要求每个数都小于，还是和小于？**
>
> 是**每个数**。中位数定义的是位置关系，不是数值之和。比如左半 [1,100] 和右半 [2,3]，左半和更大，但合并排序是 [1,2,3,100]，中位数是 2.5 不是 51。

### 3.3 为什么用二分查找

每次检查交叉条件时：

| 条件 | 问题 | 调整方向 |
|:----|:-----|:--------|
| `nums1_left > nums2_right` | nums1 左边太大 | **i 左移**（`right = i-1`） |
| `nums2_left > nums1_right` | nums1 右边太小 | **i 右移**（`left = i+1`） |

每次排除一半，这就是二分查找。

## 四、为什么在短数组上二分？

> **问：为什么要保证在较短的数组上二分？**

**答：为了保证 `j = total_left - i` 不越界。**

假设 `m=100`（长），`n=3`（短），`total_left ≈ 52`：

```
如果在长数组上取 i=60  →  j = 52-60 = -8  ❌ 数组越界！
```

在短数组上二分，`i` 的范围是 `[0, m]`。因为 `m ≤ n`，所以 `total_left ≥ m`，`j = total_left - i ≥ 0` 始终成立。

**短数组决定方向，长数组被动跟随。**

---

## 五、找到分割后如何算中位数

### 奇数情况：左半多一个

`(m+n) % 2 == 1` 时，左半比右半多 1 个元素。

**中位数 = max(左半)**

```
nums1=[1,3], nums2=[2] 总长3（奇数）
左半: [1]+[2]=[1,2]  →  max=2  ✅
右半: [3]             →  min=3
```

### 偶数情况：左右相等

`(m+n) % 2 == 0` 时，左右一样多。

**中位数 = (max(左半) + min(右半)) / 2**

```
nums1=[1,2], nums2=[3,4] 总长4（偶数）
左半: [1,2]+[3]=[1,2,3]  →  max=3
右半: []+[4]=[4]         →  min=4
中位数 = (3+4)/2 = 3.5 ✅
```

### `+1` 的作用

```python
total_left = (m + n + 1) // 2
```

| 总长 | 不加+1 | 加+1 | 效果 |
|:----|:-------|:-----|:-----|
| 3（奇） | 3//2=1 | **4//2=2** | 左2右1 ✅ |
| 4（偶） | 4//2=2 | **5//2=2** | 左2右2 ✅ |

`+1` 让奇数时左边多一个，中位数统一取 `max(左)`，不用额外判断。

## 六、完整推演

### 例1：一次找到 `nums1=[2,4,6,8]`, `nums2=[1,3,5,7,9]`

```
m=4, n=5, total_left=5
在短数组上二分: left=0, right=4

第1轮: i=2, j=3
  nums1: [2,4 | 6,8]    nums2: [1,3,5 | 7,9]
  nums1_left=4, nums1_right=6, nums2_left=5, nums2_right=7
  4≤7 ✅  5≤6 ✅  → 找到！
奇数(9) → 中位数 = max(4,5) = 5 ✅
```

### 例2：需要右移 `nums1=[1,3,5,7]`, `nums2=[2,4,6,8,10,12]`

```
m=4, n=6, total_left=5

第1轮: i=2, j=3
  [1,3 | 5,7]    [2,4,6 | 8,10,12]
  3≤8 ✅  6≤5 ❌  → nums1右边太小 → 右移 left=3

第2轮: i=3, j=2
  [1,3,5 | 7]    [2,4 | 6,8,10,12]
  5≤6 ✅  4≤7 ✅  → 找到！
偶数(10) → (max(5,4)+min(7,6))/2 = (5+6)/2 = 5.5 ✅
```

### 例3：需要左移 `nums1=[10,20,30,40]`, `nums2=[1,2,3,4,5]`

```
m=4, n=5, total_left=5

第1轮: i=2, j=3
  [10,20 | 30,40]    [1,2,3 | 4,5]
  20≤4 ❌  → nums1左边太大 → 左移 right=1

第2轮: i=0, j=5
  [ | 10,20,30,40]    [1,2,3,4,5 | ]
  nums1_left=-∞, nums2_right=+∞
  -∞≤+∞ ✅  5≤10 ✅  → 找到！
奇数(9) → 中位数 = max(-∞,5) = 5 ✅
```

## 七、算法模板

```python
def findMedianSortedArrays(self, nums1, nums2):
    # 1. 保证 nums1 是短数组
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    
    m, n = len(nums1), len(nums2)
    total_left = (m + n + 1) // 2
    left, right = 0, m
    
    while left <= right:
        i = (left + right) // 2         # 短数组分割点
        j = total_left - i              # 长数组分割点（自动确定）
        
        # 2. 取边界值（用 ±∞ 处理分割在边界的极端情况）
        l1 = nums1[i-1] if i > 0 else float('-inf')
        r1 = nums1[i]   if i < m else float('inf')
        l2 = nums2[j-1] if j > 0 else float('-inf')
        r2 = nums2[j]   if j < n else float('inf')
        
        # 3. 检查交叉条件
        if l1 <= r2 and l2 <= r1:
            # 找到正确分割
            if (m + n) % 2:
                return max(l1, l2)
            return (max(l1, l2) + min(r1, r2)) / 2.0
        elif l1 > r2:
            right = i - 1   # 左移
        else:
            left = i + 1    # 右移
```
