# LeetCode 0001 - 两数之和 (Two Sum)

## 1. 题目描述
给定一个整数数组 `nums` 和一个目标值 `target`，请你在该数组中找出和为目标值的那 **两个** 整数，并返回他们的数组下标。

## 2. 解题思路：暴力枚举 (Brute Force)
本方案采用最直观的双重循环遍历策略：
*   **外层循环**：固定第一个加数 `nums[i]`。
*   **内层循环**：在 `i` 之后的元素中寻找是否存在 `nums[j]`，使得两数之和等于 `target`。
*   **优点**：逻辑简单，无需额外的排序或空间预处理。

## 3. C 语言底层细节分析
作为信息安全专业的练习，本项目特别强调了内存管理：

*   **动态内存分配**：使用 `malloc` 在**堆 (Heap)** 上申请空间。因为局部变量数组在函数返回后会失效，必须动态分配内存才能保证数据安全传回 `main` 函数。
*   **内存连续性**：`malloc(sizeof(int) * 2)` 保证了申请到的 8 个字节在物理内存上是连续的，可以通过指针算术或数组下标安全访问。
*   **防御性编程**：在 `main` 函数结束前调用 `free(result)`，并遵循“申请与释放对应”的原则，避免内存泄漏。

## 4. 复杂度分析
*   **时间复杂度**: $O(n^2)$
    嵌套循环遍历数组，总比对次数约为 $n(n-1)/2$。
*   **空间复杂度**: $O(1)$
    除返回数组外，仅使用了固定数量的常数变量。
