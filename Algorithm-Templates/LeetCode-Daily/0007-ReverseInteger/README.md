# 0007. 整数反转（Reverse Integer）

## 一、题目理解

给你一个 32 位有符号整数 `x`，返回将 `x` 中数字部分反转后的结果。

如果反转后整数超过 32 位有符号整数范围 [−2³¹, 2³¹−1]（即 [-2147483648, 2147483647]），就返回 0。

**约束：环境不允许存储 64 位整数。**

### 示例

```
输入: x = 123     → 输出: 321
输入: x = -123    → 输出: -321
输入: x = 120     → 输出: 21    (前导零被省略)
输入: x = 0       → 输出: 0
```

## 二、算法思路

**数学法**：逐位弹出再推入，同时检查溢出。

```
原始:  123
pop:   3   2   1
result: 0 → 3 → 32 → 321
```

**关键步骤：**
1. `pop = x % 10`   → 取最后一位
2. `x /= 10`        → 去掉最后一位
3. `rev = rev * 10 + pop` → 推入结果
4. 重复直到 x = 0

**溢出检查：** 在 `rev * 10 + pop` 之前判断是否会溢出。

| 条件 | 说明 |
|:----|:------|
| `rev > INT_MAX/10` | 乘以 10 后必然溢出 |
| `rev == INT_MAX/10 && pop > 7` | 乘以 10 后加上 pop 会溢出（INT_MAX 末位为 7） |
| `rev < INT_MIN/10` | 乘以 10 后必然溢出（负方向） |
| `rev == INT_MIN/10 && pop < -8` | 乘以 10 后加上 pop 会溢出（INT_MIN 末位为 -8） |

## 三、复杂度

| 维度 | 值 |
|:----|:----|
| 时间 | O(log₁₀ n) ≈ 最多循环 10 次（32 位整数） |
| 空间 | O(1) |
