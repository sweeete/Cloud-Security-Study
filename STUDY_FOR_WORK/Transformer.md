## 一、NLP 是什么

NLP（自然语言处理）是人工智能的分支，研究如何让计算机理解、处理和生成人类语言。

**难点**：语言是离散的、有歧义的、依赖上下文的——同一个「苹果」，可以是水果也可以是公司。

## 二、序列建模的演进

### RNN（循环神经网络）

> 深度学习时代处理序列数据的经典网络——2017 年 Transformer 出现之前，它是 NLP 的主力。

**核心思想**：给网络装上「记忆」，一步一步读序列，每一步都把读到的内容融进一个记忆向量里。

**三个要点**

| 要点 | 说明 |
| --- | --- |
| 循环结构 | 每个时间步读一个词，更新隐藏状态 h，h 就是网络的「记忆」 |
| 共享权重 | 所有时间步用同一套 W——序列可任意长，参数量却不随长度增长 |
| 历史压缩 | 整句信息被逐步「压缩」进一个固定长度的向量里 |

**致命弱点**

1. **长距离依赖丢失**：开头词的信息按步衰减，长句传到结尾早就「忘」了。
2. **梯度消失 / 爆炸**：反向传播要沿时间步连乘 W，$0.8^{10} \approx 0.1$，梯度同样指数级衰减，训练不动。
3. **无法并行**：必须算完 $h_{t-1}$ 才能算 $h_t$，GPU 的并行能力用不上，训练慢。

**后续的补救与终结**

- **LSTM / GRU（1997 / 2014）**：给单元加了「门控」——遗忘门决定丢什么、输入门决定记什么，缓解了衰减问题，但要背的公式也多了。
- **Transformer（2017）**：干脆放弃「逐词压缩」，让每个词直接注意到句中所有词——距离为 1，信息不衰减，且全并行。这正是《大模型原理与架构》第 1 章讲「序列建模基础」、第 2 章讲注意力的动机所在。

### LSTM（长短期记忆网络）

1997 年 Hochreiter 和 Schmidhuber 提出的 RNN 改进版。

**核心思想**：给 RNN 加一条独立的「记忆传送带」（细胞状态 C），再用三个「门」控制信息进出——这样重要信息可以几乎无损地穿过很多时间步。

### CNN（卷积神经网络）

专门处理具有网格结构数据的神经网络——最典型的是图像（像素排成 2D 网格），也用于音频、时序。

**核心思想**：用一个小窗口（卷积核）在整张图上滑动扫描，局部提取特征并共享参数。

### MoE（Mixture of Experts，混合专家）

当前大模型的主流架构之一（DeepSeek-V3、Qwen、Mixtral 都用它）。

**核心思想**：把一个大 FFN 拆成很多个「专家」小网络，每次输入只激活其中少数几个，其余不动——用极小的计算量换取极大的参数量。

## 三、注意力机制

### Multi-Head Attention（多头注意力）

Transformer 的核心组件。

**核心思想**：把注意力机制并行地跑很多遍（很多「头」），每一遍用不同的投影矩阵，让不同的头从不同角度关注序列——然后拼接起来，一次拿到多种视角的信息。

## 四、语言模型基础

### 语言模型

**定义**：给一个词序列打分，衡量它「像不像人话」。两种等价表述：

$$P(w_1, w_2, \dots, w_n) \quad \text{或} \quad P(w_t \mid w_1, \dots, w_{t-1})$$

任何语言模型都能干三件事：**给句子打分**（判断是否通顺）、**预测下一个词**、**生成文本**。

**关键定义**：给定一个词表 V（比如 3 个词：{我, 吃, 饭}），语言模型要能给出词表上所有词的完整概率分布，且总和为 1。

**算例**

设 $P(\text{吃} \mid \text{我}) = 0.6$，$P(\text{睡} \mid \text{我}) = 0.3$，$P(\text{饭} \mid \text{我}) = 0.1$（和为 1）。那么句子「我 吃 饭」的概率就是逐步累乘：

$$P(\text{我 吃 饭}) = P(\text{我}) \times P(\text{吃} \mid \text{我}) \times P(\text{饭} \mid \text{我 吃})$$

### n-gram

NLP 里最基础的语言模型之一，思想非常朴素：**用前 n-1 个词预测下一个词**。

它不做任何「理解」，纯粹靠统计——在大量语料里数，哪个词跟在某个词序列后面出现的次数最多。

## 五、序列标注的经典方法

### 隐马尔可夫模型 HMM

**定义**：给一个观测序列，推断背后隐藏的状态序列。典型场景——**词性标注**：你看到的词是「观测」，词性是「隐藏状态」。

**两个核心假设**（这就是「隐」和「马尔可夫」的含义）

1. **马尔可夫假设**：当前状态只依赖前一状态
   $$P(z_t \mid z_1, \dots, z_{t-1}) = P(z_t \mid z_{t-1})$$
2. **观测独立假设**：当前观测只依赖当前状态
   $$P(w_t \mid z_1, \dots, z_T, w_1, \dots, w_T) = P(w_t \mid z_t)$$

**模型由三组参数构成**

| 参数 | 含义 | 例子 |
| --- | --- | --- |
| 初始概率 $\pi$ | 第一个词是各词性的概率 | — |
| 转移概率 A | 词性之间的转移 | $P(\text{动词} \mid \text{名词})$：名词后接动词很常见 |
| 发射概率 B | 某词性生成某词的概率 | $P(\text{"吃"} \mid \text{动词})$ |

**算例**：句子「我 爱 学习」，词表 {我, 爱, 学习}，标签集 {名词, 动词}。

已知条件：

- $P(\text{名词} \mid \text{名词}) = 0.4$
- $P(\text{动词} \mid \text{名词}) = 0.6$
- $P(\text{"爱"} \mid \text{动词}) = 0.5$
- $P(\text{"学习"} \mid \text{动词}) = 0.7$，$P(\text{"学习"} \mid \text{名词}) = 0.3$

那么「名词 → 动词 → 动词」这条路径的得分是（乘起来）：

$$\text{score} = P(\text{名词}) \times P(\text{"我"} \mid \text{名词}) \times P(\text{动词} \mid \text{名词}) \times P(\text{"爱"} \mid \text{动词}) \times P(\text{动词} \mid \text{动词}) \times P(\text{"学习"} \mid \text{动词})$$

**最优路径用 Viterbi 算法求**（动态规划，避免穷举所有 $2^3 = 8$ 条路径）。

**三大经典问题**：评估（前向算法）、解码（Viterbi）、训练（Baum-Welch，即 EM 算法）。

**致命缺陷**：观测独立假设太强了——它假设「词」只由自己的词性决定，因此同一个词的所有邻居信息都看不到。

> 「bank」在「river bank」（河岸）和「bank account」（银行账户）里词性完全不同，HMM 无法区分，因为「bank」本身没变。

### 条件随机场 CRF

**定义**：CRF 就是为解决 HMM 的缺陷而生的。它直接建模条件概率 $P(\text{标签序列} \mid \text{观测序列})$，不关心词是怎么生成的。

$$\text{score}(y \mid x) = \sum_t \left[ \sum_k \lambda_k f_k(y_t, y_{t-1}, x, t) \right]$$

$$P(y \mid x) = \frac{\exp(\text{score}(y \mid x))}{\sum_{y'} \exp(\text{score}(y' \mid x))}$$

**关键在于特征函数 $f_k$** ——它可以看任意信息：

- 当前词本身（「bank」是动词吗）
- 前后词的词性（**HMM 做不到！**）
- 当前词是否大写、是否含数字、是否在词典里
- 位置信息

**算例**：判断「river bank」里的「bank」，CRF 的特征可以写成：

| 特征 | 权重 $\lambda$ |
| --- | --- |
| 前一个词是「river」 | +3.0 |
| 后一个词是「the」 | +1.0 |
| 当前词小写 | +0.5 |
| 当前词出现在金融词典 | −2.0 |

总分 $= 3.0 + 1.0 + 0.5 - 2.0 = 2.5$ → 正数，倾向标为「名词（河岸）」。

如果换成「bank account」，「account」这个特征会把分数推向「银行」的标签——**HMM 完全做不到这一点**。

**总结**

| | HMM | CRF |
| --- | --- | --- |
| 类型 | 生成式（建模 $P(x, y)$） | 判别式（建模 $P(y \mid x)$） |
| 前提 | 需要假设观测独立 | 特征灵活，不计生成过程 |
| 表现 | — | 序列标注上几乎全面优于 HMM |

CRF 曾是实体识别、分词、词性标注的 SOTA。

## 六、放进你的知识框架

这三个模型和最近问的内容连成了一条完整的演进线：

**语言模型这一条线：从「打分」到「生成」**

```
n-gram（数频次）→ 神经网络 LM → word2vec → RNN/LSTM → Transformer/GPT
```

**序列标注这一条线：从「生成式」到「判别式」到「预训练」**

```
HMM → CRF → BiLSTM-CRF → BERT-CRF → 大模型直接生成标签
```

> ⚠️ 有趣的是，今天的趋势是**回归统一**：HMM 那个「隐藏状态」的思想，在 Transformer 里以「隐层表示」的形式复活了；而 CRF 层至今仍被加在 BERT 之后做实体识别（BERT-CRF 是工业界标配）。
>
> 经典方法并没有消失，它们成了新架构里的组件。
