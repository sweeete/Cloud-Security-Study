# 回答方案复盘

> **文件定位**：本文件记录六步闭环编排系统的执行复盘，供追溯和调试使用。
> **格式规范**：
> - 按六步完整记录：是什么 → 为什么 → 怎么做 → 综合方案 → 拆分任务 → 分发执行 → 验证审计
> - 每步用 `###` 三级标题分隔
> - 每步内容前标注时间戳和使用的 agent 名称
> - 如果某步跳过，标注"本步骤因 xxx 跳过"
> - 文件由编排 agent 在流程结束时自动写入（非强制，可选执行）
