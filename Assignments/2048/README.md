# 2048 小游戏

经典 2048 益智游戏的网页版实现。

## 技术栈

HTML5 + CSS3 + 原生 JavaScript (ES6+)

## 运行方式

直接在浏览器中打开 `index.html` 即可运行，无需构建工具，无需服务器。

## 操作说明

| 操作 | 按键 |
|------|------|
| 上移 | <kbd>↑</kbd> 或 <kbd>W</kbd> |
| 下移 | <kbd>↓</kbd> 或 <kbd>S</kbd> |
| 左移 | <kbd>←</kbd> 或 <kbd>A</kbd> |
| 右移 | <kbd>→</kbd> 或 <kbd>D</kbd> |
| 重新开始 | <kbd>R</kbd> |

触屏设备上直接滑动即可操作。

## 游戏规则

- 4×4 棋盘，每次移动所有方块向指定方向滑动
- 相同数字的方块碰撞后会合并为一个（数值翻倍）
- 每次移动后在空白位置随机生成一个 2（90% 概率）或 4（10% 概率）
- 合成 2048 即获胜，可选择继续挑战更高分数
- 棋盘填满且无相邻相同数字时游戏结束

## 项目结构

```
2048/
├── index.html        # 入口页面，引入所有样式和脚本
├── README.md         # 项目说明文件
├── css/
│   └── style.css     # 样式表：布局、主题色、响应式断点、CSS 动画
└── js/
    ├── game.js       # 核心算法：Board 类、滑动合并、方向移动、游戏状态检测、GameEngine 类
    ├── ui.js         # UI 渲染模块：DOM 操作、分数更新、覆盖层控制、动画管理
    └── input.js      # 输入模块：键盘事件、触屏事件
```

## 功能特性

- [x] 完整 2048 核心算法（滑动、合并、计分）
- [x] 键盘控制（方向键 + WASD + R 重新开始）
- [x] 触屏滑动支持
- [x] 分数记录与本地持久化（localStorage）
- [x] 历史最高分保存
- [x] 获胜提示与继续挑战
- [x] 游戏结束提示与重新开始
- [x] 方块出现动画（缩放）与合并动画（回弹）
- [x] 覆盖层淡入动画
- [x] 响应式设计（桌面端与移动端适配）
- [x] 模块化代码（算法 / UI / 输入 分离）
- [x] 内置单元测试（console.assert，生产环境不执行）
