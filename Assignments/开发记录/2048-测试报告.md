## 一、单元测试

> 单元测试覆盖核心算法模块（`game.js`），可在 Node.js 或浏览器控制台中独立运行，不依赖 DOM。
> 测试代码内置于 `game.js` 末尾（默认注释，取消 `/* */` 包裹后生效）。

### 1.1 滑动合并测试（slideRowLeft）

测试核心原语 `slideRowLeft(row)` —— 单行向左滑动并合并相同数字。

| 编号 | 输入 | 期望输出 | 测试内容 | 结果 |
|------|------|---------|---------|------|
| 1 | `[0, 2, 0, 2]` | `{row: [4,0,0,0], score: 4}` | 间隔相同数字合并 | ✅ 通过 |
| 2 | `[2, 2, 4, 4]` | `{row: [4,8,0,0], score: 12}` | 两组同时合并 | ✅ 通过 |
| 3 | `[2, 0, 2, 4]` | `{row: [4,4,0,0], score: 4}` | 先合并再保留 | ✅ 通过 |
| 4 | `[2, 2, 2, 0]` | `{row: [4,2,0,0], score: 4}` | 不链式合并（只合并相邻一对） | ✅ 通过 |
| 5 | `[4, 4, 4, 4]` | `{row: [8,8,0,0], score: 16}` | 四相同两两配对 | ✅ 通过 |

**代码验证**（运行输出）：
```
PASS [0,2,0,2] → [4,0,0,0]
PASS [2,2,4,4] → [4,8,0,0]
PASS [2,0,2,4] → [4,4,0,0]
PASS [2,2,2,0] → [4,2,0,0]
PASS [4,4,4,4] → [8,8,0,0]
```

### 1.4 游戏结束检测测试（isGameOver）

| 编号 | 测试棋盘 | 期望 | 说明 | 结果 |

**测试棋盘示例**（游戏结束场景）：

## 三、Bug 修复与回归测试

### 3.1 第一轮修复（P0 审计发现）

| Bug | 问题描述 | 修复方案 | 验证结果 |
|-----|---------|---------|---------|
| 🔴 输入初始化时序 | `Input.init()` 在 DOMContentLoaded 前执行，engine 为 undefined | 改为 DOMContentLoaded + requestAnimationFrame | ✅ |
| 🔴 continue-btn 冲突 | 两个模块绑定不同行为（隐藏 vs 重置） | 统一在 ui.js，调用 `engine.continueGame()` | ✅ |
| 🔴 覆盖层定位 | 相对于视口而非棋盘 | `#game-container` 加 `position: relative` | ✅ |
| 🟡 按钮重复绑定 | restart-btn 在两个模块中各绑定一次 | 统一在 ui.js | ✅ |
| 🟡 R 键默认行为 | 未 preventDefault | 添加 `event.preventDefault()` | ✅ |

### 3.2 第二轮修复（P1 审计发现）

| Bug | 问题描述 | 修复方案 | 验证结果 |
|-----|---------|---------|---------|
| 🔴 继续后获胜循环 | `hasWon` 持续被重新检测为 true | 添加 `_continueMode` 标志跳过检测 | ✅ |
| 🔴 动画清理竞态 | setTimeout 误清后续动画类 | `clearTimeout` 防竞态 | ✅ |
| 🟡 z-index 无效 | `tile-merged` 的 z-index 不生效 | `.tile` 加 `position: relative` | ✅ |

### 3.3 第三轮修复（系统检查发现）

| Bug | 问题描述 | 修复方案 | 验证结果 |
|-----|---------|---------|---------|
| 🔴 `_continueMode` 未重置 | setupNewGame 漏复位 | 加 `this._continueMode = false` | ✅ |
| 🔴 覆盖层被 buildGrid 清除 | `innerHTML=''` 摧毁覆盖层 DOM | 改用 `querySelectorAll('.tile')` 选择性清除 | ✅ |
| 🟡 合并检测假阳性 | `[2,2,4,0]` 误判 (0,1) 为合并 | `slideRowLeft` 精确追踪 `mergedColIndices` | ✅ |
